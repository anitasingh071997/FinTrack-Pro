# 📚 Browser Rendering Pipeline

When a browser loads this webpage, it performs the following steps:

1. HTML Parsing
2. Tokenization
3. DOM Tree Creation
4. CSS Parsing
5. CSSOM Tree Creation
6. Render Tree Creation
7. Layout Calculation
8. Paint
9. Composite Layers
10. Display on Screen

The project visually demonstrates this pipeline using connected cards.

---

# 🌳 DOM Tree

The browser converts every HTML element into a tree-like structure called the DOM Tree.

Example

HTML

body

├── header

├── aside

├── section

└── footer

JavaScript manipulates this DOM tree dynamically using methods like:

* createElement()
* append()
* prepend()
* remove()
* replaceWith()
* before()
* after()

---

# 🎯 Event Bubbling

During Event Bubbling, the event starts from the clicked element and moves upward.

Example

Child

↓

Parent

↓

Grandparent

The project demonstrates this behavior inside the Event Propagation section.

---

# 🎯 Event Capturing

During Event Capturing, the event starts from the outermost parent and travels down to the clicked element.

Example

Grandparent

↓

Parent

↓

Child

This project demonstrates capturing using addEventListener with the capture option enabled.

---

# 🎯 Event Delegation

Instead of attaching event listeners to every task button, a single listener is attached to the parent task container.

Benefits

* Better performance
* Less memory usage
* Handles dynamically created elements
* Cleaner code
