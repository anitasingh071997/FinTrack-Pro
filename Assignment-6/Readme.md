# 🍵 Two Leaves and a Bud Organic Tea

A responsive frontend clone of the Two Leaves and a Bud Organic Tea website built using HTML and CSS.

---

## 📌 Project Overview

This project is a modern tea brand landing page inspired by the official Two Leaves and a Bud website.

The website showcases:

* Hero Banner
* Product Showcase Cards
* Discover Tea Section
* Brand Story Section
* Customer Reviews
* Cafe & Wholesale Partner Section
* Tea Latte Promotion
* Tea Journal
* Newsletter Subscription
* Responsive Footer

The design focuses on clean layouts, typography, responsive design, and modern UI practices.
